Full-stack TypeScript

We build full-stack TypeScript applications with React on the front end and Node.js or Bun on the back end, including micro-frontend architectures that let teams ship independently.

Java and Kotlin

We design and build back-end services and web applications in Java and Kotlin with Spring Boot, from the first architecture decisions through to production.

Mobile with React Native

We build cross-platform mobile apps with React Native, and Progressive Web Apps where a browser is enough, sharing code and skills with your web stack.

Liferay

We know the Liferay platform in depth; our founder spent two years consulting at Liferay itself. We design large deployments, advise on getting the most from the platform and build on it.

Cloud on AWS and Azure

We design cloud deployment architectures on AWS and Azure, with infrastructure as code, containers and automated CI/CD pipelines that keep releases routine.

Team training

We bring your engineers up to date with modern practice across coding, deployment and operations, through training and day-to-day mentoring shaped around your company.

Questions we often hear

What does Ligas Consulting do?
Ligas Consulting is a software consultancy. We build full-stack TypeScript applications with React and Node.js, back-end systems in Java and Kotlin, mobile apps with React Native and solutions on the Liferay platform, deployed on AWS and Azure. We also train and mentor development teams.
Which technologies do you specialise in?
Full-stack TypeScript with React, Node.js and Bun is our main focus, followed by Java and Kotlin with Spring Boot. We also build mobile apps with React Native, work in depth with Liferay, and deploy to AWS and Azure.
Do you use AI in software development?
Yes. We use AI-assisted development to deliver faster, but it is always guided by experienced engineers who set the architecture, review every change and remain accountable for quality. We can also build AI-powered features into your products.
Do you offer Liferay consulting?
Yes. We know the Liferay platform in depth and advise on how to use it well in existing and upcoming projects. We also build on Liferay directly.
Can you train our development team?
Yes. Our training is shaped around your company and covers coding, deployment and operations, so your engineers can own and run what we build together.
Who have you worked with?

Who will we work with?
With Miroslav Ligas, our founder and lead consultant. He is a solution architect with over 15 years of commercial experience in full-stack TypeScript, Java and Liferay, and he stays hands-on in every engagement.
